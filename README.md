# باندورا

پروتوتایپ آمادگی آیلتس برای فارسی‌زبانان. نام محصول **Bandora / باندورا** است و وابسته به سازمان آیلتس نیست.

مسیر اصلی این است: صفحه فرود، ورود نمایشی، هدف، تعیین سطح چهار مهارت، گزارش، برنامه و داشبورد. سه سناریوی خیالی داشبورد و گزارش و برنامه را با هم عوض می‌کنند. نمره‌ها با فرمول همین مخزن، در `lib/model.ts` و روی کلاینت، حساب می‌شوند و رسمی نیستند. هیچ نمره یا زمان پیشرفتی تضمین نمی‌شود.

سرور Node.js با Express فقط همین رابط React را سرو می‌کند. در توسعه Vite داخل Express است و در تولید خروجی `dist/` با بازگشت به `index.html` بالا می‌آید. API، احراز هویت واقعی و پرداخت اضافه نشده است.

جزئیات محصول در [docs/README.md](docs/README.md) است. وضعیت هر قابلیت، محاسبه‌شده یا نمایشی یا آینده، در [docs/capability-matrix.md](docs/capability-matrix.md) آمده است.

## اجرا

```bash
npm install
npm run dev
```

برنامه روی [http://127.0.0.1:38471](http://127.0.0.1:38471) بالا می‌آید. نسخهٔ قابل‌دیدن برای همه روی [GitHub Pages](https://rahas3064-web.github.io/IELTS/) است. `npm run dev` همان `node server.js` است.

```bash
npm run build
npm start
npm run typecheck
npm run lint
```

`npm start` با `NODE_ENV=production` فایل‌های ساخته‌شده را سرو می‌کند.

## صداقت محصول

صوت شنیدن گفتار مصنوعی مرورگر است. نوشتن و صحبت کردن با قاعده طول نمره می‌گیرند و تلفظ نمره ندارد. پرداخت، ایمیل، پوش، هوش مصنوعی و کنترل دسترسی سرور وصل نیستند. اگر اتصال را از نوار بالا قطع کنید، ساعت آزمون ادامه پیدا می‌کند و ارسال انجام نمی‌شود.

## ECC

پیکربندی عامل Cursor از [ECC](https://github.com/affaan-m/ECC) نسخهٔ ۲.۲.۳ (کامیت `90606c8`) با دستور رسمی `./install.sh --target cursor typescript --enable-hooks` داخل `.cursor/` نصب شده است. قانون‌ها، مهارت‌ها، عامل‌های `ecc-*` و هوک‌های پروژه اینجاست. این فایل‌ها سایت عمومی را عوض نمی‌کنند.
