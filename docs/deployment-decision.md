# تصمیم میزبانی

این سند پیشنهاد است و هیچ منبع پولی ساخته نشده. آدرس گیت‌هاب و GitHub Pages عوض نشده‌اند.

| لایه | پیشنهاد | هزینه تقریبی | چرا هنوز اجرا نشده |
| --- | --- | --- | --- |
| فرانت | همان GitHub Pages تا جایگزین تأیید شود | رایگان | Pages از قبل هست |
| API نود | یک سرویس کوچک با متغیر محیطی، نزدیک کاربر | معمولاً طرح رایگان محدود یا چند دلار در ماه | باید میزبان را شما انتخاب کنید |
| PostgreSQL | سرویس مدیریت‌شده با پشتیبان روزانه | طرح رایگان کوچک یا حدود چند دلار | بدون تأیید شما ساخته نمی‌شود |

متغیرها: `DATABASE_URL`, `PORT`. نمونه در `.env.example` است و رمز واقعی ندارد.

انتشار: فرانت با `vite build --base /IELTS/` و شاخه `gh-pages`. برگشت: برگرداندن همان شاخه به کامیت قبلی. API جدا برمی‌گردد با استقرار نسخه قبلی فرایند نود. تا وقتی API عمومی تأیید نشده، ورود نمایشی روی Pages باید بماند.

برای ادامه لازم است بگویید کدام میزبان API و پایگاه را می‌خواهید، یا اینکه فعلاً فقط روی همین مرورگر بمانیم.
