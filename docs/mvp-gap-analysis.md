# فاصله تا MVP

| قابلیت | وضعیت | فاصله |
| --- | --- | --- |
| صفحه فرود، RTL، چهار مهارت، برنامه، سناریو | موجود در کلاینت | برند و کنتراست در این مرحله به‌روز شد |
| نمره | محاسبه محلی، غیررسمی | جدول رسمی تأیید نشده |
| حساب کاربر | نمایشی، رمز ذخیره نمی‌شود | تا PostgreSQL و نشست سرور نیاید واقعی نیست |
| ماندگاری پاسخ | فقط همین مرورگر | مهاجرت `001_initial.sql` نوشته شده و اجرا نشده |
| هوش مصنوعی | نیست | بدون تأیید هزینه وصل نمی‌شود |
| پرداخت | نمایشی | خارج از این مرحله |
| دیپلوی | GitHub Pages برای فرانت | بک‌اند روی Pages اجرا نمی‌شود |
| آزمون | ۶ تست واحد بعد از این مرحله | مسیر مرورگر خودکار هنوز نیست |

MVP وقتی کامل است که باگ بحرانی بسته باشد، سفر اصلی تست شده باشد، طرح پایگاه و مهاجرت وجود داشته باشد، و احراز هویت واقعی قبل از داده شخصی وصل شده باشد. این مخزن هنوز به آن نقطه نرسیده است.
