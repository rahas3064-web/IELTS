# معماری

## انتخاب پروتوتایپ

رابط با React، TypeScript و Vite ساخته شده و `server.js` همان فرآیند Express است که آن را سرو می‌کند. در توسعه Vite به‌صورت middleware است و در تولید `dist/` با بازگشت SPA سرو می‌شود. مسیرها در مرورگر با react-router هستند. این سرور API، نشست یا پرداخت ندارد و نمره در `lib/model.ts` روی کلاینت می‌ماند. این انتخاب برای نسخه نمایشی قطعی محصول نهایی نیست.

## پیشنهاد نسخه واقعی

| لایه | پیشنهاد | جایگزین | چرا پیشنهاد |
| --- | --- | --- | --- |
| Frontend | همین کلاینت React با Vite و react-router | جدا کردن API وقتی تیم بخواهد | مسیرها و RTL همین حالا این‌جا هستند |
| Backend | سرویس HTTP جدا، مثلاً روی Node یا هر زبان تیم | مسیرهای کوچک فقط برای یک MVP خیلی محدود | نمره، صوت و صف باید از رابط جدا باشند. Express امروز فقط فایل کلاینت را سرو می‌کند |
| Database | Postgres | SQLite فقط برای توسعه محلی | رابطه سؤال، تلاش و نسخه لازم است |
| Auth | نشست httpOnly یا استاندارد تیمی | رمز خانگی | پروتوتایپ عمداً رمز ندارد |
| State | سرور منبع حقیقت؛ کلاینت پیش‌نویس آزمون | فقط localStorage | چند دستگاه و حذف حساب |
| Validation | یک طرح مشترک برای فرم و API | اعتبار فقط در فرم | فرم امروز دور زده می‌شود |
| Error | کد پایدار و حالت خالی/خطا/کند | پیام آزاد | QA به کد تکیه می‌کند |
| AI | سرویس جدا با ورودی خروجی مشخص | صدا زدن مدل از کامپوننت | امروز وصل نیست و نباید پنهان شود |
| Audio | ذخیره شیء با رضایت جدا | نگه داشتن صوت در مرورگر | تلفظ بدون این سرویس نمره ندارد |
| Question bank | جدول نسخه‌دار | فایل داخل ریپو | انتشار نباید تلاش قدیمی را عوض کند |
| Analytics | خط لوله با رضایت و بدون متن پاسخ | رویداد داخل جدول پاسخ | کاتالوگ همین حالا جداست |
| Notifications | صف ایمیل/پوش | فقط داخل برنامه، مثل امروز | امروز صف نیست |
| Export | job پس‌زمینه | CSV سمت کلاینت، مثل امروز | PDF واقعی job می‌خواهد |
| Security | مجوز روی هر مسیر | مخفی کردن دکمه | `lib/access.ts` فقط دمو است |
| Testing | آزمون مدل نمره به‌علاوه مسیر مرورگر | فقط کلیک دستی | فرمول در `lib/model.ts` خالص است |
| Deploy | محیط جدا برای وب و API | یک فرآیند واحد در شروع | بازیابی نسخه را ساده‌تر می‌کند |
| Monitoring | خطا، تأخیر، و سلامت سرویس نمره | فقط لاگ محلی | نمره غلط باید دیده شود |

## پوشه‌های فعلی

`server.js` فرآیند Express، `index.html` و `src/main.tsx` ورود کلاینت، `src/routes.tsx` مسیرها، `app/globals.css` سبک، `components/ui` پایه، `components/features` صفحه‌ها، `components/shell` قاب، `lib/model.ts` محاسبه، `lib/questions.ts` بانک، `lib/scenarios.ts` سه پرسونا، `docs/` قرارداد.

## پوشه‌های پیشنهادی بعدی

`services/scoring`، `services/plan`، `services/speech`، `db/migrations`، `tests/model`، `tests/flows`.

## حالت

یک تابع `buildView` داشبورد، گزارش و برنامه را از یک ورودی می‌سازد. آزمایشگاه فقط اورراید همان ورودی است. این قرارداد باید در سرور هم بماند تا صفحه‌ها از هم فاصله نگیرند.
