# امنیت و حریم خصوصی

## امروز در پروتوتایپ

- ورود و خروج فقط پرچم محلی است. رمز نوشته نمی‌شود و هش هم نمی‌شود.
- بازیابی رمز نامه‌ای نمی‌فرستد.
- نقش در رابط عوض می‌شود و سرور آن را چک نمی‌کند.
- رضایت تحلیل اختیاری است و پیش از ثبت‌نام خاموش است. حساب نمونه برای دیدن رویدادها آن را روشن می‌کند و در پروفایل خاموش می‌شود.
- خروجی JSON پروفایل و رویداد است، نه رمز.
- حذف، کلید محلی را برمی‌دارد.
- رویداد امنیتی محلی: ورود، خروج، خروجی، حذف، تغییر رضایت.
- داده نمونه ایمیل‌های `example.com` است.

## الزام نسخه واقعی

- نشست کوتاه، چرخش، و خروج از همه دستگاه‌ها.
- رمز با الگوریتم استاندارد، هرگز در لاگ.
- مجوز روی هر مسیر API.
- رضایت جدا برای تحلیل و برای صوت. سابقه رضایت با زمان و متن.
- کمینه‌سازی: تلفن فقط اگر واقعاً لازم شد.
- دسترسی، اصلاح، خروجی و حذف حساب. مهلت پیشنهادی حذف: ۳۰ روز مهلت برگشت، بعد پاک‌سازی پاسخ آموزشی.
- نگهداری پاسخ آزمون حداکثر ۲۴ ماه پس از آخرین فعالیت، مگر تکلیف قانونی دیگری باشد. این عدد پیشنهاد است.
- جدول پروفایل از جدول پاسخ جدا باشد. رویداد تحلیلی متن پاسخ نداشته باشد.
- ثبت ورود ناموفق، تغییر نقش، خروجی و حذف.
- API با محدودیت نرخ، TLS، و رمزنگاری دیسک. آزمون این کنترل‌ها جزو تعریف انجام نسخه سروری است.

در Canva یا در این پروتوتایپ، دیدن فرم به‌معنی انجام این کنترل‌ها نیست.
