# سیستم طراحی

توکن‌ها در `app/globals.css` هستند و مؤلفه‌های پایه از shadcn/ui با Base UI آمده‌اند: دکمه، ورودی، کارت، نشان، تب، دیالوگ، ورقه، منو، انتخاب، متن چندخطی، سوئیچ، جداکننده، پیشرفت، راهنما، جدول، آواتار، اسکرول، آکاردئون، چک‌باکس، هشدار.

## رنگ

- برند: بنفش `oklch(0.45 0.16 285)` روی متن روشن. در تم تاریک بنفش روشن‌تر با متن تیره تا کنتراست بماند.
- سطح: یاسی خیلی روشن، کارت تقریباً سفید.
- معنا: `--success`، `--warning`، `--info`، `--destructive`. هر هشدار مهم آیکن یا واژه هم دارد.
- نمودار: بنفش، سبزآبی، کهربایی، سرخ، خاکستری. جدول هم‌ارز برای نمودار روند وجود دارد.

## تایپ

Vazirmatn برای رابط فارسی و لاتین. Literata فقط برای متن آزمون انگلیسی (`.exam-serif`). مقیاس متن روی `html[data-text]` برابر ۱۵، ۱۶٫۵ و ۱۸٫۵ پیکسل است.

## فاصله، شعاع، حالت

شعاع پایه `0.8rem`. کارت‌ها خط مویی دارند، نه سایه سنگین. حالت‌های دکمه: پیش‌فرض، حاشیه‌دار، شبح، مخرب، غیرفعال. ورودی خطا `aria-invalid` و خط قرمز دارد. تمرکز با `outline` و حلقه shadcn دیده می‌شود. کاهش حرکت فاصله انیمیشن را به نزدیک صفر می‌رساند.

## جهت

`dir` و `lang` روی `documentElement` از زبان می‌آیند. فاصله‌ها منطقی‌اند (`ps`/`pe`/`ms`). متن انگلیسی آزمون `dir="ltr"` است. ورقه منو در فارسی از راست باز می‌شود.

## استفاده

دکمه اصلی برای اقدام مسیر (شروع، ارسال). دکمه حاشیه‌دار برای کار دوم. نشان وضعیت قابلیت از `StateBadge` می‌آید و در راهنما و صفحه سیستم طراحی تکرار شده است.

تم روشن، تاریک و سیستم با `next-themes` و کلید `theme` می‌ماند.
