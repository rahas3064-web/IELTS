# قرارداد API پیشنهادی

این مسیرها در پروتوتایپ صدا زده نمی‌شوند. سطح دسترسی باید روی سرور باشد، نه فقط در رابط.

پیش‌فرض‌ها: JSON، شناسه رشته‌ای، خطای `{ "error": { "code", "message" } }` با ۴۰۰ اعتبار، ۴۰۱ نشست، ۴۰۳ نقش، ۴۰۴ نبود، ۴۰۹ تعارض نسخه، ۴۲۹ محدودیت، ۵۰۳ وابستگی.

| روش | مسیر | نقش | کار |
| --- | --- | --- | --- |
| POST | `/v1/auth/register` | عمومی | ساخت حساب. خروجی بدون رمز |
| POST | `/v1/auth/login` | عمومی | نشست. رمز هرگز در پاسخ نیست |
| POST | `/v1/auth/logout` | یادگیرنده | باطل کردن نشست |
| POST | `/v1/auth/password-reset` | عمومی | نامه یک‌بارمصرف |
| GET/PATCH | `/v1/me` | یادگیرنده | پروفایل و هدف |
| POST | `/v1/placement` | یادگیرنده | شروع تلاش |
| PUT | `/v1/placement/{id}/answers` | یادگیرنده | ذخیره افزایشی |
| POST | `/v1/placement/{id}/submit` | یادگیرنده | فقط اگر چهار مهارت بسته شده باشند |
| GET | `/v1/placement/{id}/report` | صاحب یا مدیر | نمره، بازه، شواهد، اطمینان |
| GET/PATCH | `/v1/plan` | یادگیرنده | برنامه و ویرایش |
| POST | `/v1/exercises/{id}/attempts` | یادگیرنده | نتیجه |
| POST | `/v1/mocks/{id}/attempts` | یادگیرنده | آزمونک |
| GET | `/v1/history` | یادگیرنده | فیلتر مهارت و تاریخ |
| POST | `/v1/exports` | یادگیرنده | CSV یا PDF job |
| GET/PATCH | `/v1/notifications` | یادگیرنده | خواندن و تنظیم |
| POST | `/v1/assistant/turns` | یادگیرنده | بعداً؛ امروز وجود ندارد |
| POST | `/v1/tickets` | یادگیرنده | بازخورد |
| PATCH | `/v1/admin/tickets/{id}` | پشتیبان یا مدیر | وضعیت |
| CRUD | `/v1/admin/questions` | محتوا | نسخه و انتشار |
| GET | `/v1/admin/analytics` | مدیر | تجمیع، بدون متن پاسخ |
| POST | `/v1/events` | یادگیرنده با رضایت | فقط ویژگی‌های کاتالوگ |
| DELETE | `/v1/me` | یادگیرنده | حذف حساب و داده آموزشی |

سرویس نمره ورودی‌اش پاسخ عینی به‌علاوه متن نوشتن/صحبت و خروجی‌اش نمره، بازه، اطمینان، معیار و فهرست شواهد است. سرویس برنامه ورودی‌اش نمره، هدف، دقیقه، روز و تاریخ و خروجی‌اش تسک و توضیح اثر است. سرویس صوت فقط با رضایت جدا و بعد از نسخه ۰٫۴.

تعارض: اگر دو دستگاه یک تلاش باز را عوض کنند، سرور باید `version` تلاش را بخواهد و ۴۰۹ بدهد. سیاست آزمون زمان‌دار عوض نمی‌شود: ساعت سرور ادامه دارد.
