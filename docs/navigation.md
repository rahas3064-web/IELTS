# صفحات و ناوبری

ناوبری یادگیرنده در `components/shell/app-shell.tsx` است. در عرض کم، چهار میانبر پایین صفحه و بقیه داخل منو هستند.

## عمومی

| مسیر | نقش |
| --- | --- |
| `/` | فرود |
| `/login` `/signup` `/forgot-password` | ورود نمایشی |
| `/plans` | مقایسه Free و Pro، بدون خرید |

## یادگیرنده، بعد از ورود

| مسیر | نقش |
| --- | --- |
| `/onboarding` | هدف مرحله‌ای |
| `/placement` | انتخاب مهارت و قاعده زمان |
| `/placement/[skill]` | اجرای یک مهارت |
| `/placement/report` | گزارش؛ مسیر ایستا بر مسیر پویا مقدم است |
| `/dashboard` | نمای وضعیت |
| `/roadmap` `/plan` | مرحله و هفته قابل‌ویرایش |
| `/practice` `/practice/[id]` | کتابخانه و یک تمرین |
| `/mocks` `/mocks/[id]` | آزمونک |
| `/progress` `/archive` | تاریخچه و خطا |
| `/reports` | CSV و چاپ |
| `/notifications` `/assistant` `/help` `/feedback` | اعلان، دستیار، راهنما، تیکت |
| `/profile` | زبان از نوار بالا، تم، متن، نقش، حذف محلی |
| `/lab` | سناریو |

## مدیر

`/admin` و زیرمسیرهای analytics، content، users، feedback، experiments، roadmap، settings، design-system.

## قفل

بدون `account` هر مسیر گروه `(app)` به ورود برمی‌گردد. بدون اتمام هدف، فقط خود آنبوردینگ باز است. گزارش شخصی وقتی هر چهار مهارت ارسال شده باشند از داده خود کاربر ساخته می‌شود؛ تا آن لحظه، اگر منبع داده سناریو باشد، گزارش سناریو نشان داده می‌شود.
