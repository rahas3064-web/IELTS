# ممیزی فنی

تاریخ بررسی: ۲۳ اکتبر ۲۰۲۶. شاخه `main`. دیپلوی عمومی فعلی GitHub Pages است و این ممیزی روی سورس محلی انجام شده، نه با فرض برابری قطعی با آخرین بیلد صفحات.

## معماری فعلی

- رابط: React 19 و TypeScript، ورود از `src/main.tsx`، مسیرها در `src/routes.tsx` با React Router.
- ساخت: Vite. توسعه و تولید هر دو از `server.js` (Express) روی پورت ۳۸۴۷۱. GitHub Pages فقط فایل ایستای `dist/` را با پیشوند `/IELTS/` سرو می‌کند و Node را اجرا نمی‌کند.
- حالت: یک `localStorage` در `lib/store.tsx`. نمره در `lib/model.ts` روی کلاینت.
- آزمون خودکار قبل از این مرحله: هیچ فایلی نبود.
- گردش‌کار GitHub Actions: نیست.

## خط پایه قبل از تغییر این مرحله

- `tsc --noEmit`: خروج ۰.
- `eslint`: خروج ۰.
- `npm test`: اسکریپت وجود نداشت.

## چه چیزی پیاده شده است

محاسبه‌شده در مرورگر: نمره غیررسمی، شاخص آمادگی، برنامه، سه سناریو، CSV.

نمایشی: ورود، نقش مدیر، صوت شنیدن، تصحیح نوشتن و صحبت، اتصال قطع، پرداخت، دستیار.

نیست: PostgreSQL، نشست سرور، احراز هویت واقعی، ارزیابی هوش مصنوعی زنده.

## امنیت

رمز در کلاینت ذخیره نمی‌شود. کلید محرمانه‌ای در سورس فرانت نیست. نقش مدیر فقط در رابط عوض می‌شود و مجوز سرور نیست. `npm audit --omit=dev` چند آسیب‌پذیری high در زنجیره `shadcn` / `fast-glob` / `braces` نشان داد. این‌ها ابزار توسعه و رجیستری کامپوننت‌اند، نه مسیر اجرای کاربر. `npm audit fix --force` اجرا نشد چون می‌تواند وابستگی را بشکند.
