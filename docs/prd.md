# PRD — IELTS Readiness 0.1

## مسئله

فارسی‌زبانی که بدون معلم خصوصی برای IELTS آماده می‌شود، معمولاً سطح خودش، فاصله تا هدف، و کاری که این هفته باید بکند را در یک تصویر واحد ندارد. محصول باید این تصویر را بسازد، بدون آنکه نمره یا زمان رسیدن را تضمین کند.

## کاربر اصلی

زبان‌آموز مستقل، فارسی‌زبان، Academic یا General Training. نقش‌های Content Manager، System Admin و Support Agent برای عملیات بعدی هستند و در این نسخه فقط در رابط شبیه‌سازی می‌شوند.

## غیرهدف نسخه ۰٫۱

حساب واقعی، پرداخت، صوت رسمی، ارزیابی انسانی یا مدل زبانی، همگام‌سازی سرور، و کنترل دسترسی بک‌اند.
